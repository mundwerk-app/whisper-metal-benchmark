# Run 2026-05-05-r01 — Apple M3 Ultra Baseline

First production run of the Mundwerk whisper.cpp Metal benchmark suite.

## Setup

- **Hardware:** Apple M3 Ultra (24 performance cores + 8 efficiency, 80 GPU cores, 512 GB RAM)
- **OS:** macOS 26.4.1 (build 25E253)
- **whisper.cpp:** v1.8.4
- **Build flags:** `-DGGML_METAL=ON -DGGML_ACCELERATE=ON -DCMAKE_BUILD_TYPE=Release`
- **Sample:** JFK inaugural excerpt (`samples/jfk.wav`), 11 s, English, 22 words

## Results

| Model | Size (MB) | Median Inference (ms) | RTF | Speed vs Real-Time | ms/word |
|-------|-----------|------------------------|-----|---------------------|---------|
| tiny | 74.1 | 136.1 | 0.012 | **80.9×** | 6.2 |
| base | 141.1 | 161.5 | 0.015 | 68.1× | 7.3 |
| small | 465.0 | 309.5 | 0.028 | 35.5× | 14.1 |
| medium | 1462.7 | 713.9 | 0.065 | 15.4× | 32.4 |
| large-v3-turbo | 1549.3 | 622.9 | 0.057 | **17.7×** | 28.3 |

## Headline Findings

1. **Even `tiny` runs at 80× real-time** on M3 Ultra — interactive dictation has zero perceivable delay across the entire model lineup.
2. **`large-v3-turbo` outperforms `medium`** despite being a larger model on disk. The turbo variant uses a reduced decoder (~4 layers vs 32) and is genuinely faster while keeping near-large-v3 quality. For dictation, this is the sweet spot.
3. **Linear-ish scaling** with model size in ms/word (6 → 7 → 14 → 32 → 28 ms/word), with the turbo variant breaking the trend.
4. **All five models stay well under real-time** — the bottleneck on M3 Ultra is never inference; it's only model load (one-time, <2 s for medium tier).

## Reproducibility

```bash
# 1. Build whisper-cli with examples enabled (one-time, ~3 min)
git clone https://github.com/ggerganov/whisper.cpp
cd whisper.cpp && mkdir -p build-bench && cd build-bench
cmake .. -DCMAKE_BUILD_TYPE=Release -DGGML_METAL=ON -DGGML_ACCELERATE=ON \
  -DBUILD_SHARED_LIBS=OFF -DWHISPER_BUILD_EXAMPLES=ON
make -j$(sysctl -n hw.ncpu) whisper-cli

# 2. Download models (~3.7 GB total)
for m in tiny base small medium large-v3-turbo; do
  bash ../models/download-ggml-model.sh "$m"
done

# 3. Run inference, 3× per model
for m in tiny base small medium large-v3-turbo; do
  for i in 1 2 3; do
    /usr/bin/time -p ./bin/whisper-cli \
      -m ../models/ggml-$m.bin \
      -f ../samples/jfk.wav \
      -l en -otxt false -pp false 2>&1 | grep "total time"
  done
done
```

Median over 3 runs reported; the script that automates this is `Scripts/whisper-bench.py` in the Mundwerk app repo (closed-source, but the inference layer above is fully reproducible standalone).

## Limitations

- Single-host, single-sample. Cross-hardware comparison requires runs on M1/M2/M3 base/Pro/Max variants (PRs welcome).
- No warmup run — first of three captures model-load overhead. For load-time-only metric, see `load_time_ms` in `results.json`.
- English-only sample. German + German-English mixed samples are on the roadmap (Mundwerk's primary use case is code-switching).
